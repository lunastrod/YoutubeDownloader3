[Español](#español) | [English](#english)

---

## English

Windows tool to download YouTube playlists.

### Installation and Usage
1. **Download as zip from GitHub**:
   - Click the green "Code" button
   - Click on Download zip
2. **Unzip**
   - Unzip the downloaded file
3. **Run**
   - Run YTDownloader.exe
   - Note: If Windows shows a protection warning, click "More info" and then "Run anyway".

## Español

Herramienta de Windows para descargar playlists de YouTube.

### Instalación y Uso
1. **Descarga como zip de GitHub**:
   - Pulsa en el botón verde "Code"
   - Pulsa en Download zip
2. **Descomprimir**
   - Descomprime el zip
3. **Ejecutar**
   - Ejecuta YTDownloader.exe
   - Nota: Si Windows muestra un aviso de protección, pulsa en "Más información" y luego en "Ejecutar de todos modos".
